# Documentação — PD Barber

Esta pasta reúne os principais documentos de apoio do projeto **PD Barber**, utilizados para organizar o desenvolvimento da interface, manter a padronização visual e facilitar a consulta das decisões tomadas durante a construção do site.

## Conteúdos da documentação

Os documentos desta seção podem incluir:

- especificações das telas;
- organização do UI Design;
- estrutura de navegação entre páginas;
- padrões de responsividade;
- diretrizes de espaçamento e proporção;
- componentes reutilizáveis;
- referências de tipografia e cores;
- fluxo de agendamento;
- documentação das versões Desktop e Mobile.

## Figma

O projeto visual completo pode ser acessado pelo link abaixo:

No Figma estão organizadas as etapas de desenvolvimento visual do projeto, incluindo wireframes, UI Design e versões das telas para Desktop e Mobile.

## Estrutura principal das telas

O projeto atualmente contempla:

1. Início
2. Serviços
3. Detalhes do Serviço
4. Profissionais
5. Galeria
6. Sobre a Barbearia
7. Planos e Mensalidades
8. Agendamento
9. Confirmar Agendamento
10. Agendamento Confirmado

## Objetivo desta pasta

O objetivo desta documentação é manter uma referência única entre **design e implementação**, permitindo que as telas desenvolvidas no Figma permaneçam alinhadas ao código HTML e CSS do projeto.

Sempre que houver mudanças importantes no fluxo, layout, responsividade ou componentes, a documentação desta pasta deve ser atualizada junto ao projeto.
